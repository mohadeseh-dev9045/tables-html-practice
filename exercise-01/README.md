## 📝 نکات مهم این تمرین (Table)
سناریو : برنامه هفتگی یک اکادمی آموزش برنامه نویسی

### ساختار جدول

* `table` → ساخت جدول
* `caption` → عنوان جدول
* `thead` → بخش سرستون‌ها
* `tbody` → داده‌های اصلی جدول
* `tfoot` → اطلاعات پایانی یا خلاصه جدول
* `tr` → یک ردیف
* `th` → سلول عنوان
* `td` → سلول داده

---

### دسترس‌پذیری (Accessibility)

* برای عنوان ستون‌ها از `scope="col"` استفاده کن.

```html
<th scope="col">نام دوره</th>
```

---

### ادغام سلول‌ها

* `rowspan` → ادغام عمودی سلول‌ها

```html
<td rowspan="2">شنبه</td>
```

* `colspan` → ادغام افقی سلول‌ها

```html
<td colspan="6">تعداد کل دوره‌ها: 5 دوره</td>
```

---

## ❌ مشکلاتی که داشتی و راه‌حل آن‌ها

### 1. قرار دادن `<p>` داخل `tfoot`

❌

```html
<tfoot>
  <p>تعداد کل دوره‌ها: 5 دوره</p>
</tfoot>
```

✅

```html
<tfoot>
  <tr>
    <td colspan="6">تعداد کل دوره‌ها: 5 دوره</td>
  </tr>
</tfoot>
```

**دلیل:** داخل `table` فقط تگ‌های مخصوص جدول (`tr`، `th`، `td`) باید قرار بگیرند.

---

### 2. نمایش عجیب `tfoot`

❌ فکر می‌کردی `tfoot` باید همیشه آخر کد و آخر نمایش باشد.


مرورگر ممکن است `tfoot` را قبل از `tbody` پردازش کند، اما از نظر معنایی متعلق به انتهای جدول است.

---

### 3. استفاده از `rowspan`

❌ ممکن بود بعد از `rowspan` دوباره سلول «شنبه» را بنویسی.

```html
<td rowspan="2">شنبه</td>
...
<td>شنبه</td>
```



```html
<td rowspan="2">شنبه</td>
...
<!-- دیگر ستون روز را تکرار نمی‌کنیم -->
```

**دلیل:** `rowspan` خودش چند ردیف را پوشش می‌دهد.

---

### 4. استفاده از `colspan`

 بدون `colspan`:

```text
| تعداد کل دوره‌ها | | | | | |
```



```html
<td colspan="6">
  تعداد کل دوره‌ها: 5 دوره
</td>
```

**دلیل:** یک سلول کل عرض جدول را می‌گیرد.

---

##  نکات حرفه‌ای

* `caption` اولین فرزند `table` باشد.
* تعداد ستون‌های همه ردیف‌ها باید با هم هماهنگ باشد.
* `th` برای عنوان‌ها و `td` برای داده‌ها استفاده می‌شود.
* برای خلاصه جدول در `tfoot` می‌توان از `th` نیز استفاده کرد:

```html
<tfoot>
  <tr>
    <th colspan="6">
      تعداد کل دوره‌ها: 5 دوره
    </th>
  </tr>
</tfoot>
```

---

##  چک‌لیست مرور سریع

```text
table → ساخت جدول
caption → عنوان جدول
thead → سرستون‌ها
tbody → داده‌های اصلی
tfoot → خلاصه و اطلاعات پایانی
tr → ردیف
th → عنوان ستون/ردیف
td → داده
scope="col" → عنوان مربوط به ستون
rowspan → ادغام عمودی
colspan → ادغام افقی
```
