سناریو

شما مسئول طراحی پنل مدیریت پروازهای یک فرودگاه هستی.

جدول باید اطلاعات پروازهای امروز را نمایش دهد.

جمع‌بندی نکات مهم جدول‌ها برای نوت 

✅ table → ساخت جدول

✅ caption → عنوان جدول

✅ tr → یک ردیف

✅ th → سلول عنوان

✅ td → سلول داده

✅ thead → بخش هدر

✅ tbody → بخش اصلی

✅ tfoot → بخش پایانی

✅ colspan → ادغام چند ستون

✅ rowspan → ادغام چند ردیف

✅ scope="col" → عنوان یک ستون

✅ scope="row" → عنوان یک ردیف

✅ scope="colgroup" → عنوان چند ستون

✅ scope="rowgroup" → عنوان چند ردیف
